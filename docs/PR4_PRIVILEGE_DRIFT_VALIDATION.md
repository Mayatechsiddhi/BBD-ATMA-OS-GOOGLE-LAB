## Finding and correction

The previous local helper added grants and narrowed one Membership table grant, but did not reject TRUNCATE, grant options or other pre-existing excess ACLs. The old readiness guard covered role flags/ownership/RLS but not effective table/column ACL drift.

The shared runtime contract now audits effective permissions (including PUBLIC), role flags/memberships, ownership, schema/database creation and delegation, table/column/sequence/function access and explicit dangerous default ACLs. It runs in provisioning and readiness/health/scoped transactions. Local provisioning audits before and after a transaction of intended grants. It rejects drift unchanged; no blanket revoke, ALTER ROLE, ownership transfer, password change or CASCADE is used to "repair" an existing role. Missing intended grants remain repeatably provisionable. Review the precise scope and remediation process in TENANT_ISOLATION.md.
